No templates, no page builders. Every one of these is hand-built, and every one is still running.

## ◢ Selected work

### Scroll films

- **[Spider-Man](https://github.com/lianbeast/Spider-Man)** — a scroll film on React Three Fiber. One page, one canvas, six acts. Every value is a pure function of scroll position, so there is nothing to keep in sync.
- **[Personal-Site](https://github.com/lianbeast/Personal-Site)** — five sticky, full-viewport scenes that read like a controlled descent, tracked by a fixed altitude HUD. CSS and SVG only: no WebGL, no network data on the critical path.
- **[EliteHuman](https://github.com/lianbeast/EliteHuman)** — scroll-driven 3D brand site. Four chapters, plus a browsable archive of all 105 marks.

### 3D & brand sites

- **[Lian-Arch-Linux-Site](https://github.com/lianbeast/Lian-Arch-Linux-Site)** — Arch Linux as an interactive 3D experience. React Three Fiber + Vite.
- **[debian-linux-site](https://github.com/lianbeast/debian-linux-site)** — Debian 13 landing page. Animated Three.js hero and a bash terminal that actually works. Zero build step.

### Tools

- **[GitHub-Repos](https://github.com/lianbeast/GitHub-Repos)** — a self-contained browser for every public repository I have. Search, filter by language and type, sort, save favourites. No API limits.
- **[coolerdash-arch-lcd](https://github.com/lianbeast/coolerdash-arch-lcd)** — a C telemetry suite driving a CoolerDash LCD: animated overview plus CPU, GPU, liquid and power pages.

### Client & side builds

- **[resume-website](https://github.com/lianbeast/resume-website)** — career site with three experience tiers: Lite, Standard, and Immersive 3D, with the career path mapped across the United States.
- **[The-Sleep-Etiquette](https://github.com/lianbeast/The-Sleep-Etiquette)** — prelaunch landing page with a separate working area for the future store.
